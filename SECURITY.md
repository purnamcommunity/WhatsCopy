# Security Policy

WhatsCopy is designed to avoid collecting or transmitting private data.

## Privacy And Security Boundaries

WhatsCopy must not:

- Send network requests.
- Include analytics, telemetry, or tracking.
- Read WhatsApp databases.
- Read WhatsApp private app storage.
- Scrape message history.
- Inspect network traffic.

WhatsCopy may only copy text the user has actively selected when the user presses Command-C and WhatsApp is the frontmost app.

## Reporting A Vulnerability

If you find a vulnerability or privacy issue, please avoid public disclosure until it can be reviewed. Open a private security advisory on GitHub if available, or contact the maintainer through the repository's preferred private channel.

Please include:

- A clear description of the issue.
- Steps to reproduce.
- The macOS and WhatsApp versions involved.
- Any suggested fix, if known.
